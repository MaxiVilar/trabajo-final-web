
# Meliquina Hostel

Página web de Meliquina Hostel, ubicado en Villa Meliquina, Neuquén, Argentina.

El proyecto permite conocer las habitaciones disponibles, consultar sus características y precios, y realizar una simulación de reserva mediante un carrito de compras.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Fetch API
- LocalStorage
- Formspree

## Funcionalidades

- Visualización de habitaciones.
- Carga de datos mediante Fetch API.
- Agregar habitaciones al carrito.
- Modificar cantidades y eliminar habitaciones.
- Cálculo automático del total.
- Guardado del carrito mediante LocalStorage.
- Formulario de contacto con Formspree.
- Diseño adaptable a diferentes dispositivos.
